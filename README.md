# Apex PC Optimizer & Speed Booster ⚡

Apex PC Optimizer & Speed Booster is a powerful, lightweight Windows desktop application designed to optimize system performance, clean junk files, free up memory, and tweak registry settings for maximum efficiency. 

Built using **Python** and a modern dark-themed GUI powered by **CustomTkinter**, this tool automates several advanced Windows optimization tasks that typically require manual configuration or command-line execution.

---

## 🌟 Key Features

### 📊 1. System Performance Dashboard
* **Real-time Monitoring**: Track live CPU, Memory, and Disk usage with dynamic progress bars.
* **Storage Overview**: View total, used, and free disk space at a glance.
* **Restore Point Creator**: Quick access to create a Windows System Restore Point before executing any cleaning or tweaking operations.

### 🧹 2. Deep System Junk Cleaner
Scan and safely remove unnecessary junk files across various categories:
* **User Temp Files**: Temporary files generated by user-space applications.
* **System Temp Files**: Windows system-level temp files.
* **Prefetch Cache**: Windows application launch prefetch caches.
* **System Logs**: Setup and diagnostic logs (`.log`, `.txt`, `.bak`, `.tmp`).
* **Browser Caches**: Safely clear cache files for Google Chrome, Microsoft Edge, and Mozilla Firefox.

### ⚙️ 3. Startup & Process Management
* **Active Process Viewer**: View real-time resource consumption (CPU/Memory) of running processes and terminate heavy tasks instantly.
* **Startup Item Manager**: Scan and manage applications configured to run at startup (stored in registry paths like Run/RunOnce), helping you improve boot times.

### ⚡ 4. Advanced Performance Tweaks
* **Memory Optimizer**: Free up physical RAM by flushing active user process working sets and purging the Windows Standby memory list via Native Windows APIs (`ntdll.dll`/`psapi.dll`).
* **Network Booster**: Flush the Windows DNS cache (`ipconfig /flushdns`) to resolve DNS resolution issues.
* **Power Plan Optimization**: View system power schemes and switch to performance-enhancing plans.

---

## 🛠️ Technology Stack
* **Language**: Python 3.x
* **GUI Library**: [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) (Modern Flat UI wrapper for Tkinter)
* **System Monitoring**: `psutil`
* **Windows API Integration**: Built-in Python `ctypes` (for interacting with system-level DLLs: `kernel32`, `advapi32`, `psapi`, `ntdll`)
* **Registry Controls**: `winreg` (for managing startup settings and power plans)

## 🚀 Getting Started

### Prerequisites
* **Operating System**: Windows 10 or 11 (requires Administrative privileges for most features).
* **Python**: Python 3.8 or higher.

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shubh-jaiswal-897/Core-PC-Monitor.git
   cd Core-PC-Monitor
   ```

2. **Install Dependencies**:
   Install the required Python modules using `pip`:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application**:
   Ensure you run the terminal or command prompt as **Administrator** so the optimizer has the correct privileges:
   ```bash
   python app.py
   ```
   *(Note: The application includes auto-elevation logic which will prompt for User Account Control (UAC) administrative permission automatically if not already running as Admin).*

---

## 🔒 Safety & Administrator Privileges
Because this utility manages system-level configurations, registry paths, physical memory states, and system folders (like `C:\Windows\Prefetch`), it requires **Administrator privileges** to perform most actions.

For safety, the application includes a **Restore Point creation button** on the Dashboard. It is highly recommended to create a restore point before running optimization tweaks.
